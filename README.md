# File Statistics Script

Розширений bash-скрипт для рекурсивного підрахунку файлів та їхнього загального розміру.

## Можливості
- **Підрахунок за розширенням**: Можливість фільтрації файлів за певним розширенням (наприклад, `.txt`, `.sh`).
- **Вибір директорії**: Скрипт приймає шлях до директорії як аргумент командного рядка.
- **Рекурсивність**: Автоматичний пошук у всіх піддиректоріях.
- **Підрахунок розміру**: Відображення загального розміру знайдених файлів у зручному форматі (B, KB, MB, GB).

## Використання

1. **Надання прав на виконання**:
   ```bash
   chmod +x count_files.sh
   ```

2. **Запуск для поточної директорії (всі файли)**:
   ```bash
   ./count_files.sh
   ```

3. **Запуск для конкретної директорії**:
   ```bash
   ./count_files.sh /шлях/до/директорії
   ```

4. **Пошук файлів з певним розширенням у директорії**:
   ```bash
   ./count_files.sh /шлях/до/директорії розширення
   ```
   *Приклад:* `./count_files.sh /var/log log`

## Вимоги
- Bash
- Встановлені утиліти `find`, `awk`.
